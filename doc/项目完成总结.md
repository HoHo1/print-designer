## 🛠️ 技术栈

### 后端
- **框架**：Spring Boot 3.2.x
- **持久层**：MyBatis-Plus
- **数据库**：MySQL 8.0
- **缓存**：Redis
- **API文档**：Knife4j/Swagger
- **工具**：Hutool、ZXing、OpenPDF

### 前端
- **框架**：Vue 3.4.x
- **语言**：TypeScript 5.x
- **构建**：Vite 5.x
- **UI库**：Element Plus 2.x
- **状态管理**：Pinia 2.x
- **路由**：Vue Router 4.x
- **条码**：jsbarcode、qrcode
- **导出**：html2canvas、jspdf

### 部署
- **容器化**：Docker + Docker Compose
- **反向代理**：Nginx
