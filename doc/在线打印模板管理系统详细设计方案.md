### 2.3 分表策略

考虑未来数据量增长，设计以下分表策略：

1. **打印任务表（sys_print_task）**：按月分表
   - 表名格式：`sys_print_task_YYYYMM`
   - 适用场景：高并发打印任务记录
   - 优点：数据查询范围小，便于归档清理

2. **操作日志表（sys_operation_log）**：按月分表
   - 表名格式：`sys_operation_log_YYYYMM`
   - 保留周期：6个月
   - 定期归档旧数据

#### 3.1.3 撤销/重做实现

采用命令模式（Command Pattern）实现撤销/重做功能：

```typescript
interface Command {
  execute(): void;
  undo(): void;
  redo(): void;
}

class HistoryManager {
  private undoStack: Command[] = [];
  private redoStack: Command[] = [];
  private maxSize = 50;

  execute(command: Command) {
    command.execute();
    this.undoStack.push(command);
    this.redoStack = []; // 清空重做栈
    if (this.undoStack.length > this.maxSize) {
      this.undoStack.shift();
    }
  }

  undo() {
    const command = this.undoStack.pop();
    if (command) {
      command.undo();
      this.redoStack.push(command);
    }
  }

  redo() {
    const command = this.redoStack.pop();
    if (command) {
      command.redo();
      this.undoStack.push(command);
    }
  }
}
```

```java
            .collect(Collectors.toMap(
                DataSourceAdapter::getType,
                Function.identity()
            ));
    }

    public DataSourceAdapter getAdapter(String type) {
        return adapters.get(type);
    }
}
```

#### 3.3.2 分页算法

```typescript
interface PageBreakResult {
  pages: RenderedPage[];
  totalPages: number;
}

function calculatePageBreaks(
  elements: RenderElement[],
  pageHeight: number,
  margins: PageMargins
): PageBreakResult {
  const availableHeight = pageHeight - margins.top - margins.bottom;
  const sortedElements = sortByPosition(elements);
  const pages: RenderedPage[] = [];
  let currentPage: RenderElement[] = [];
  let currentPageHeight = 0;

  for (const element of sortedElements) {
    const elementHeight = element.y + element.height;

    if (currentPageHeight + elementHeight > availableHeight) {
      // 需要分页
      const repeatable = extractRepeatableElements(currentPage);
      pages.push({
        elements: currentPage,
        repeatableHeader: repeatable.header,
        repeatableFooter: repeatable.footer
      });
      currentPage = [...repeatable.header];
      currentPageHeight = calculateTotalHeight(repeatable.header);
    }

    currentPage.push(element);
    currentPageHeight += element.height;
  }

  if (currentPage.length > 0) {
    pages.push({ elements: currentPage, repeatableHeader: [], repeatableFooter: [] });
  }

  return { pages, totalPages: pages.length };
}
```

```typescript
// 元素拖拽核心逻辑
class DragManager {
  private isDragging = false;
  private startX = 0;
  private startY = 0;
  private currentElement: HTMLElement | null = null;

  onMouseDown(e: MouseEvent, element: HTMLElement) {
    this.isDragging = true;
    this.startX = e.clientX;
    this.startY = e.clientY;
    this.currentElement = element;
    element.classList.add('dragging');
  }

  onMouseMove(e: MouseEvent, gridSize: number) {
    if (!this.isDragging || !this.currentElement) return;

    const deltaX = e.clientX - this.startX;
    const deltaY = e.clientY - this.startY;

    let newX = this.currentElement.offsetLeft + deltaX;
    let newY = this.currentElement.offsetTop + deltaY;

    // 吸附到网格
    newX = Math.round(newX / gridSize) * gridSize;
    newY = Math.round(newY / gridSize) * gridSize;

    this.currentElement.style.left = `${newX}px`;
    this.currentElement.style.top = `${newY}px`;

    this.startX = e.clientX;
    this.startY = e.clientY;
  }

  onMouseUp() {
    if (this.currentElement) {
      this.currentElement.classList.remove('dragging');
    }
    this.isDragging = false;
    this.currentElement = null;
  }
}
```

## 9. 技术难点与解决方案

### 9.1 可视化设计器难点

| 难点 | 挑战 | 解决方案 |
|------|------|----------|
| 元素定位精度 | 浏览器DPI差异导致位置不准 | 使用mm为单位，内部统一转换为px，保存时转换回mm |
| 元素层级管理 | 多元素重叠时的层级控制 | 使用z-index栈管理，支持置顶/置底/上移/下移 |
| 复杂表格分页 | 动态表格跨页时表头重复 | 实现智能分页算法，预计算每页可容纳行数 |
| 撤销重做性能 | 大量元素的历史记录占用内存 | 使用命令模式增量存储，限制历史深度50步 |
| 条码二维码渲染 | 高精度打印要求清晰度 | 使用Canvas离屏渲染，导出时使用高DPI |

### 9.2 打印渲染难点

| 难点 | 挑战 | 解决方案 |
|------|------|----------|
| 多浏览器兼容性 | 不同浏览器打印效果不一致 | 使用PDF作为中间格式，确保一致性 |
| 分页计算准确性 | 内容高度计算与实际打印差异 | 提供打印校准功能，允许微调 |
| 中文支持 | 部分字体在PDF中显示异常 | 使用内置中文字体（思源黑体） |
| 大表格性能 | 数千行数据渲染慢 | 使用虚拟滚动，只渲染可视区域 |

### 9.3 数据源集成难点

| 难点 | 挑战 | 解决方案 |
|------|------|----------|
| SQL注入风险 | 直接执行SQL的安全问题 | 使用参数化查询，预编译SQL模板 |
| API超时处理 | 外部API响应慢影响打印 | 设置超时时间，异步加载数据 |
| 数据格式转换 | 不同数据源返回格式各异 | 使用JSONPath统一解析 |
